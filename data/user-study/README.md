# User study: System Usability Scale

`sus_responses.csv` holds the answers of the 8 participants who completed the
SUS survey, one row each. They used the earlier, text-only version of Itera.

- Answers run from 1 (strongly disagree) to 5 (strongly agree).
- Rows are sorted by score. S1 to S8 are not participant numbers, so a row
  can't be matched to an interview.
- No names, emails or dates are included.

| Column | Statement |
|---|---|
| q1 | I think that I would like to use this system frequently. |
| q2 | I found the system unnecessarily complex. |
| q3 | I thought the system was easy to use. |
| q4 | I think that I would need the support of a technical person to be able to use this system. |
| q5 | I found the various functions in this system were well integrated. |
| q6 | I thought there was too much inconsistency in this system. |
| q7 | I would imagine that most people would learn to use this system very quickly. |
| q8 | I found the system very cumbersome to use. |
| q9 | I felt very confident using the system. |
| q10 | I needed to learn a lot of things before I could get going with this system. |

**Scoring (Brooke, 1996):** odd statements count as answer - 1, even ones as
5 - answer; the sum is multiplied by 2.5.

**Result:** mean 87.5, median 87.5, sample SD 9.2, range 77.5 to 100.
