# Itera Studio Manual Evaluation Checklist

Use this checklist during demos or user testing to quickly score search quality.

## How to Use

1. Start the app and run each query below in the search bar.
2. Compare what you see with the expected outcome.
3. Check each checklist item.
4. Give one overall rating from 1 to 5 for that query.

Rating scale:
- 1 = poor
- 2 = weak
- 3 = acceptable
- 4 = strong
- 5 = excellent
